## 📌 Название проекта

**Система рекомендаций городских маршрутов** (City Route Recommender)

---

## 🎯 Назначение

Приложение предназначено для подбора персонализированных прогулочных маршрутов по городу. Система анализирует интересы пользователя и на их основе формирует рекомендации маршрутов, соответствующих его предпочтениям.

Основная цель — упростить процесс планирования досуга: вместо ручного поиска мест и построения пути пользователь получает готовые маршруты, подобранные под его интересы.

---

## 👥 Целевая аудитория

*   **Жители города** — для организации прогулок и досуга выходного дня.
*   **Туристы** — для знакомства с городом по персонализированным маршрутам.
*   **Любители тематических прогулок** — интересующиеся архитектурой, историей, стрит-артом, парками и т.д.
*   **Организаторы досуга** — гиды, экскурсоводы, локальные сообщества.

---

## 🌍 Предметная область

Предметная область — **организация городского досуга и туризма**, а именно: формирование, хранение и рекомендация маршрутов прогулок по городу на основе интересов пользователя.

Система работает с географическими точками (достопримечательности, парки, кафе, культурные объекты) и объединяет их в тематические маршруты. Ключевая особенность — **персонализация**: один и тот же набор точек может формировать разные маршруты в зависимости от интересов конкретного пользователя.

---

## 🧩 Основные сущности

| Сущность | Описание |
|---|---|
| **Пользователь** | Зарегистрированный пользователь системы: учётные данные, профиль, роль, набор интересов. |
| **Интерес** | Тег или категория (архитектура, история, парки, стрит-арт и т.п.), связывающая пользователя и маршруты. |
| **Маршрут** | Тематический маршрут по городу с описанием, протяжённостью, длительностью и автором. |
| **Место** | Географическая точка (достопримечательность, парк, кафе) с названием, адресом и координатами. |
| **Точка маршрута** | Место в составе конкретного маршрута с порядковым номером. |
| **Отзыв** | Оценка (1–5) и комментарий пользователя к маршруту. |
| **Рекомендация** | Маршрут, предложенный пользователю, с коэффициентом релевантности. |
| **Избранное** | Маршруты, сохранённые пользователем. |

### Связи между сущностями

*   `Пользователь` **M:N** `Интерес` — пользователь выбирает свои интересы.
*   `Маршрут` **M:N** `Интерес` — маршрут относится к одной или нескольким категориям.
*   `Маршрут` **M:N** `Место` — через `Точку маршрута` с порядковым номером.
*   `Пользователь` **1:N** `Маршрут` — пользователь является автором маршрутов.
*   `Пользователь` **1:N** `Отзыв`, `Маршрут` **1:N** `Отзыв` — пользователь оставляет отзывы о маршрутах.
*   `Пользователь` **1:N** `Рекомендация`, `Маршрут` **1:N** `Рекомендация` — пользователю рекомендуются маршруты.
*   `Пользователь` **M:N** `Маршрут` — через `Избранное`.

Подробная схема базы данных — в [отчёте ПР3](docs/pr3/README.md).

## ⚙️ Основные функции

*   **Регистрация и авторизация пользователя.**
*   **Управление профилем** — указание и редактирование интересов.
*   **Ведение базы маршрутов** — создание, редактирование, удаление маршрутов (CRUD).
*   **Управление точками маршрута** — добавление и упорядочивание точек следования.
*   **Формирование рекомендаций** — подбор маршрутов на основе совпадения интересов пользователя с тематикой маршрута.
*   **Поиск и фильтрация маршрутов** — по городу, интересам, протяжённости.
*   **Оценка маршрутов** — возможность оставить отзыв и оценку.
*   **Избранное** — сохранение понравившихся маршрутов.
*   **Просмотр маршрута на карте** (в перспективе).
