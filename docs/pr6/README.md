## 2. Доработка индивидуального проекта

**Репозиторий:** https://github.com/vaar38/city-routes

**Структура шаблонов.** Каталог `templates/` уровня проекта подключён в `settings.py` (`"DIRS": [BASE_DIR / "templates"]`), шаблоны приложений лежат в `<app>/templates/<app>/`.

| Шаблон | Назначение |
|---|---|
| `templates/base.html` | каркас: `{% load static %}`, Bootstrap, свой CSS, логотип, навигация, блоки `title` / `content`, подвал, JS |
| `templates/includes/navigation.html` | меню через `{% url 'homepage:index' %}`, `{% url 'routes:list' %}`, `{% url 'recommendations:list' %}` |
| `homepage/index.html`, `homepage/404.html` | главная и собственная страница 404 |
| `routes/route_list.html` + `includes/route_card.html` | список маршрутов: цикл с `{% empty %}`, карточка через `{% include %}` |
| `routes/route_detail.html` | маршрут; `{% if route %}` / `{% else %}` + статус 404 во view |
| `recommendations/recommendation_list.html`, `recommendation_detail.html` + `includes/recommendation_status.html` | рекомендации; один фрагмент статуса используется на двух страницах |

**Views.** Все view-функции переведены на `render(request, шаблон, context)`; для отсутствующего объекта передаётся `status=404`. Функция `page()` из ПР5 удалена, HTML в Python больше не формируется.

**Фильтры:** `routes|length`, `route.name|default:"Без названия"`, `capfirst`, `floatformat`.

**Статические файлы** (`homepage/static/homepage/`): `css/style.css` (шапка, карточки маршрутов, тег тематики, бейджи статуса), `js/main.js` (подставляет текущий год в подвал), `img/logo.svg`. `python manage.py findstatic` находит все три файла.

**Данные** по-прежнему загружаются из JSON через `storage.py` в объекты `Route`, `User`, `Recommendation`; Django ORM не используется.
