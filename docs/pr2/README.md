## 2. Индивидуальный проект

**Название:** Система рекомендаций городских маршрутов (№408)
**Репозиторий:** https://github.com/vaar38/city-routes

Начальный сценарий ПР1 (один пользователь, один маршрут, одна рекомендация в отдельных переменных) переработан в консольную программу, работающую со списками маршрутов, пользователей и рекомендаций. Проверки из `create_user()` и `create_route()` ПР1 перенесены в `add_user()` и `add_route()`, функция `check_interest()` ПР1 используется при подборе маршрутов.

**Модули и функции:**

| Модуль | Функции |
|---|---|
| `main.py` | `main()` — меню и цикл; сценарии `search_routes`, `filter_routes`, `create_new_route`, `remove_route`, `create_new_user`, `edit_interest`, `pick_routes`, `create_new_recommendation`, `reject_recommendation` |
| `routes.py` | `add_route`, `delete_route`, `find_route`, `find_route_by_id`, `check_route_length`, `filter_routes_by_length` (генератор), `filter_routes_by_interest`, `sort_routes` (lambda), `show_routes` |
| `users.py` | `add_user`, `find_user`, `find_user_by_id`, `change_interest`, `show_users` |
| `recommendations.py` | `check_interest`, `recommend_routes`, `is_route_recommended`, `create_recommendation`, `dismiss_recommendation`, `get_recommendation_status`, `show_recommendations` |
| `storage.py` | `load_json` / `save_json` (`with`, `FileNotFoundError`, `JSONDecodeError`), `load_*` / `save_*` |
| `utils.py` | `input_int`, `input_float`, `input_text` — повторный запрос при ошибке ввода |

**Данные:** списки словарей в `data/routes.json`, `data/users.json`, `data/recommendations.json`. Рекомендация хранит `route_id`, `user_id` и признак `is_dismissed`; отклонённая рекомендация не удаляется и не мешает создать новую.

**Качество кода:** аннотации типов у всех функций, `flake8` без замечаний, 17 тестов `pytest` в `tests/` (маршруты, пользователи, рекомендации, JSON-хранилище) проходят.
